#  Práctica Teórico-Práctica de Recursividad 
 **Asignatura:** Algoritmos Clásicos y Estructuras de Datos 
 **Institución:** Pontificia Universidad Católica Madre y Maestra (PUCMM) 

Este repositorio contiene la resolución integral de la práctica de recursividad, enfocada en el análisis, transformación y rediseño de algoritmos clásicos.

##  Organización del Repositorio 

El proyecto está dividido en dos componentes principales.

** Archivos de texto (`.txt`):** Contienen las respuestas detalladas y razonadas a cada uno de los incisos de la práctica. Aquí se encuentran los análisis de complejidad, los esquemas de los árboles de llamadas y las defensas técnicas de por qué un rediseño mejora o altera el comportamiento algorítmico.

** Archivos de código (`.java`):** Nombrados según la estructura `ejercicio_1.java`, `ejercicio_2.java`, etc. Estos archivos contienen tanto el código base proporcionado  como las versiones rediseñadas e implementadas en Java estándar (sin uso de colecciones prohibidas).

## Estructura de los Ejercicios 

* ** Ejercicio 1 - Factorial:** Análisis de recursión lineal.
* ** Ejercicio 2 - Fibonacci:** Trazado de subproblemas repetidos.
* ** Ejercicio 3 - Torres de Hanoi:** Demostración de recursividad.
* ** Ejercicio 4 - Mutaciones de código:** Rediseños aplicados a fragmentos de código.
